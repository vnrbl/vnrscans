## 🌙 Theme Toggle

### How to Change Theme:
1. **Desktop**: Click the sun/moon/monitor icon in navbar
2. Select your preference:
   - ☀️ **Light** - Bright mode
   - 🌙 **Dark** - Dark mode (default)
   - 💻 **System** - Follows your device

### Theme Preview:
```
Light Mode:  White background, dark text
Dark Mode:   Dark background, light text
System:      Matches your OS theme
```

## ⚙️ Reader Settings

### Access: User Menu → Settings

### Available Options:

#### 1. Reading Direction
- **LTR** (Left to Right) - Western style
- **RTL** (Right to Left) - Manga style
- **Vertical** - Webtoon style

#### 2. Reading Mode
- **Page by Page** - Traditional reading
- **Continuous Scroll** - Webtoon mode

#### 3. Page Fit
- **Fit to Width** - Full width
- **Fit to Height** - Full height
- **Original Size** - No scaling

#### 4. Image Quality
- **High** - Best quality (default)
- **Medium** - Balanced
- **Low** - Data saver mode

#### 5. Auto-scroll Speed
- Slider: 0-100%
- 0 = Disabled
- 100 = Fastest

## ✨ Recommendations (For You)

### How It Works:
1. Click "For You" in navbar
2. View personalized recommendations
3. Based on:
   - Your reading history
   - Favorite genres
   - Highly-rated series
   - Series you haven't read

### Two Sections:

#### "For You"
- AI-scored recommendations
- Top 20 suggestions
- Scored by rating + genre match

#### "Based on Your Favorite Genres"
- Genre-specific suggestions
- Excludes series you've read
- Sorted by relevance

### Requirements:
- Must be logged in
- Must have reading history
- Auto-generates on first visit

## 👤 User Status Indicators

### Where to See:
Click your user icon → See at top of dropdown

### Displayed Info:

#### Level Badge
```
👤 Level 15
```
- Calculated from XP
- Formula: `FLOOR(SQRT(xp) / 2) + 1`
- Higher level = more reading!

#### VIP Badge
```
⭐ VIP
```
- Premium member indicator
- Gold gradient badge
- Special perks (coming soon)

#### Reading Streak
```
🔥 7 days
```
- Consecutive reading days
- Resets if you skip a day
- Build your streak!

#### XP Progress Bar
```
350/100 XP to Level 16
━━━━━━━━━━━━━━━━━━ 50%
```
- Visual progress indicator
- Shows XP to next level
- Motivates continued reading

### How to Earn XP:
- **+10 XP** per chapter read
- Read daily to maintain streak
- Level up by reading more!

## 🆘 Troubleshooting

### Theme not changing?
- Clear browser cache
- Hard refresh (Ctrl+F5)
- Check localStorage

### Recommendations empty?
- Read at least 5 series
- Wait a few seconds to generate
- Refresh the page

### Streak not updating?
- Must read at least one chapter
- Check timezone settings
- Log in daily

### Random button not working?
- Check internet connection
- Refresh page
- Try again

### Settings not saving?
- Check localStorage enabled
- Don't use incognito mode
- Clear browser data
